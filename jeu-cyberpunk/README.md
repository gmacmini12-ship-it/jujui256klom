# Néon District

Prototype de ville cyberpunk explorable à la première personne (Three.js, tout est généré par le code).

```bash
npm install
npm run dev
```

Puis ouvrir l'adresse affichée (http://localhost:5173).

Commandes : ZQSD ou flèches pour bouger, souris pour regarder, Maj pour courir, Espace pour sauter, M pour le son, Échap pour la pause.
