# RÉMANENCE

Exploration à la première personne dans Hikari, ville cyberpunk de 2076 (Three.js, tout est généré par le code).

```bash
npm install
npm run dev
```

Puis ouvrir l'adresse affichée (http://localhost:5173). L'écran d'accueil permet de reprendre la partie sauvegardée ou d'en commencer une nouvelle.

Commandes : ZQSD (WASD) ou flèches pour bouger, souris pour regarder, Maj pour courir, Espace pour sauter, E pour interagir, F pour fumer, J pour la frise de l'absence, P pour la finesse des pixels, M pour le son, Échap pour la pause.

Documentation : `docs/pitch.md` (présentation), `docs/plan.md` (plan), `docs/architecture.md` (code, extensions, tests).
